Network ACLs and security groups

By the end of this unit you’ll be able to follow a packet and tell which rule lets it through or stops it, whether that’s a network ACL or a security group, inbound or outbound, stateless or stateful.

About 10 minutesNo account needed5 steps

Northgate Freight is a made-up haulier that is moving off vSphere. The rules and output in this unit are real. Northgate’s network admin wants the web tier to take traffic from the internet and the app tier to take none.

Every statement and output in this unit comes from real runs in a lab account, apart from the review question. The NSX comparisons are only rough mappings. We left out some columns from the output and shortened the IDs.

Step 1 · Explore the parts

↑ tap any box

Network ACL, inbound

An ACL applies to a subnet, not to a server. Every subnet has exactly one ACL, and one ACL can serve many subnets. Rules run top to bottom, with the deny rule last, and traffic that matches no rule is dropped.

From NSX: roughly the gateway firewall. An ACL applies to a subnet and has no state.

Watch for this. An ACL is stateless. A reply is a separate packet that the ACL checks on its own, so the web ACL needs reply rules such as allow-web-replies-in.

Network ACL, outbound

Each direction has its own rules. The web ACL lets replies to web requests leave with allow-replies-out, and SSH replies go back to your address only.

Watch for this. Two DNS rules let a server ask IBM’s resolvers for names. Without them a server can’t look up any name, even when its web traffic is allowed.

Security group, inbound

A security group applies to a server’s network interface, not to a subnet. It holds allow rules only, and traffic that matches no rule is dropped. A rule’s remote can be an address, a CIDR block or another security group.

From NSX: roughly the distributed firewall, applied at the interface.

Security group, outbound

A security group is stateful: a rule that allows traffic one way also allows the replies.

Watch for this. A new group has no rules at all, outbound as well, so every group in the lab gets an outbound allow rule. Here it’s web-all-out.

Path A. A browser on the internet asks the web server for a page on port 80. Which rules let the request in?

Show the answer

Both rules. The packet needs an allow at both layers, and in the lab’s test the ACL allowed port 80 inbound and so did the security group.

Path A, the reply. The page comes back. Which layer needs a rule of its own for the reply?

Show the answerThe ACL needs a rule for the reply, because it is stateless.

The ACL checks the reply on its own, and allow-replies-out lets it leave. The security group is stateful, so a rule that allows traffic one way also allows the replies.

Path B. The web server calls the app server on port 8080. Which two rules on the app side let it in?

Show the answer

The ACL rule allow-vpc-in takes traffic from inside the VPC range. The security group rule app-8080-in names vpct-prod-web-sg as its remote, so it covers every web server in that group, now and later.

Path C. A host on the internet connects straight to the app server. What does the app ACL do?

Show the answer

The app ACL stops the packet. It takes no traffic that starts on the internet, and its rules for outside addresses cover only replies, which are web replies and DNS answers. Everything else meets deny-all-in.

Step 4 · Design it

Pick the layer for each need

Choose an answer for each need, then open the worked answer.

Need A. Northgate will add web servers next year, and they must reach the app tier on port 8080 without anyone editing the app rules. What would you use?

Show the worked answer

A rule that names a security group applies to every target the group is attached to, now and later, so a new web server needs no change to the app group.

Need B. No server in the app subnets may take a connection that starts on the internet. What would you use?

Show the worked answer

The app ACL takes no traffic that starts on the internet, and it covers the whole subnet, so it covers every server. A security group covers one interface at a time.

Need C. Northgate’s network admin wants SSH to work from the admin’s own address only. Where do you name that address?

Show the worked answer

Both SSH rules, and the reply rule that matches each, name your own public address as a /32. The ACL drops anyone else’s SSH packets before they reach a server. If your address changes, replace the rules.

Step 5 · Check yourself

Three questions

Review question from Unit 2.1. A subnet is created without naming a network ACL. Which one does it take?

Show the answer

Each new subnet takes the VPC’s default network ACL and default route table. The lab then attaches an ACL for each tier.

You’ve just created a new security group and it has no rules. What can the servers in it send?

Show the answer

A new group has no rules at all, outbound as well. The lab adds an outbound allow rule to each group.

Two security groups are on one interface. One allows port 22 and the other doesn’t mention it. Is port 22 open?

Show the answer

IBM combines the rules of every attached group, and the least restrictive rule wins.

Remember

A packet needs an allow at the ACL and at the security group. The ACL sits on the subnet and is stateless. The security group sits on the interface and is stateful. A timeout doesn’t tell you which one dropped the packet.
