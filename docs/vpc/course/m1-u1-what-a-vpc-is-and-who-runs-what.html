Unit 1 of Module 1

What a VPC is, and who runs what

By the end you can say what a VPC is, which parts of it are regional and which are zonal, what IBM creates for you with a new VPC, and what you create yourself.

About 10 minutesNo account needed5 steps

Northgate Freight is moving its vSphere estate to IBM Cloud VPC. The company is made up; the output in this unit is real. Its admins ask first: what do we get when we create a VPC?

Every line of output and every statement in this unit comes from real runs in a lab account. The vSphere comparisons are rough mappings.

Step 1 · The shape

A VPC is regional. A subnet is zonal.

A VPC is a private network in one region. A region holds separate data centres called zones, and the VPC can span all of them.

A subnet is bound to one zone and cannot span zones or regions. A server also lives in one zone. Every subnet in a VPC reaches every other subnet through the implicit router, across zones, with no routes to add. IBM provides that router in every VPC.

From vSphere: roughly, a region is a separate site with its own vCenter, a zone is a separate cluster with its own power and network, a VPC is an NSX tenant network, and a subnet is an NSX segment placed in one zone. These are rough mappings, not IBM statements.

Watch for this. IBM maps zone names such as us-east-1 to physical zones separately for each account. The data centre behind a zone name can differ in your account.

Step 2 · Explore the parts

One VPC, read from its own output

↑ tap any box

Identity

You choose the name. IBM sets the rest. Status available is what IBM reports once the VPC exists.

Watch for this. The VPC is created without --classic-access, so Classic access is false. IBM marks that flag as deprecated and says to use a Transit Gateway to connect VPCs to the classic network.

Resource group

You choose it when you create the VPC. Every IAM-enabled resource belongs to one resource group, and you cannot change the choice afterwards.

Watch for this. If you name no resource group, IBM puts the resource in the Default resource group. Name it in every create command.

Three defaults

IBM creates these with every VPC. A server made with no security group joins the default one. A subnet made with no network ACL gets the default ACL. A subnet made with no route table uses the default one.

Watch for this. The names here were chosen by you. vpc-create has no option to name the defaults, so IBM gives them random words, such as tremble-admit-study-angelic. The lab renames each one straight away.

DNS

IBM sets this, and you can change it. The resolver type names where the VPC gets its DNS servers. system is IBM's default type, and the two servers are IBM's DNS servers.

A later module changes the type for DNS sharing.

Step 4 · Predict

Pick an answer, then see what really happened

Northgate creates vpct-prod with --address-prefix-management manual. The VPC exists and reports available.

Straight after, you run ibmcloud is vpc-address-prefixes vpct-prod. What does it print?

Show the answerYou add them.

With manual, IBM creates no address prefixes. With auto, the setting IBM uses when you leave the flag out, IBM creates one default address prefix in each zone. Northgate chose manual because it will join this VPC to others with a Transit Gateway, and the prefixes must not overlap.

You list the routes in the default route table with ibmcloud is vpc-routing-table-routes. How many are there?

Show the answerEmpty on purpose.

The default route table has no routes. Traffic that matches no route in it is looked up in the VPC's system-implicit routing table, which holds a route to the CIDR of each subnet in the VPC.

Step 5 · Check yourself

Three questions

Which of these can span the zones of a region?

Show the answer

A VPC is regional and spans the zones of its region. A subnet belongs to one zone, and so does a server.

A server in zone 1 must reach a server in zone 2 of the same VPC. What routing do you add?

Show the answer

Every subnet in a VPC reaches every other subnet through the implicit router, across zones, with no routes to add. Whether the traffic is allowed is a separate question, which Module 2 covers.

Which of these does IBM create for you with a new VPC?

Show the answer

IBM creates the three defaults. With manual address prefix management it creates no address prefixes, and it creates no subnets either. You create those.
