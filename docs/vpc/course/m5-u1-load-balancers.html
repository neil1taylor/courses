Load balancers

By the end you can choose between an application and a network load balancer, read a pool and its health, and say why a pool member shows faulted.

About 10 minutesNo account needed5 steps

Northgate Freight is a made-up haulier moving its vSphere estate to IBM Cloud VPC. Its web tier and its app tier each need a load balancer. The commands and output below are real, from a test account.

Every command and output in this unit comes from real runs in a lab account, apart from the review question. The vSphere comparison is a rough mapping.

Step 1 · Explore the parts

One load balancer, four parts

An application load balancer in front of two web servers takes four commands to build. Select a part of the drawing to see what it does and which lines make it. You can also click a line.

↑ tap any box

Load balancer

A public application load balancer gets a host name that maps to one or more public addresses. IBM says the addresses can change with maintenance and scaling, so you send traffic to the name, not to an address.

From vSphere: the closest term is the NSX load balancer. It is a rough match.

Watch for this. Create it on three subnets in three zones. IBM says that gives the load balancer appliances in each zone, which is how it keeps working if a zone fails. In the run it took 234 seconds to become active.

Listener

The front-end port that receives requests. A load balancer takes up to 10 listeners. This one listens for HTTP on port 80 and sends what it receives to the pool.

Watch for this. The listener takes the pool's ID. The pool's name gives pool_not_found.

Pool

The back-end servers, with a method for choosing between them and a health check. IBM offers round-robin (the default), weighted round-robin and least connections. A pool holds up to 50 servers, and they must be in the same region and VPC as the load balancer.

The health check here is an HTTP request for / on port 80, every 5 seconds, with 2 retries and a 2 second timeout.

Watch for this. A weight from 0 to 100 only counts under weighted round-robin. A weight of 0 sends no new connections and lets existing ones finish.

Security group

The load balancer gets its own security group. It sends its health checks and its requests from that group.

Watch for this. A new security group allows nothing outbound. Without the outbound rule every pool member is faulted and requests get a 503.

ibmcloud is security-group-create vpct-prod-web-alb-sg vpct-prod --resource-group-name vpct-lab
ibmcloud is security-group-rule-add vpct-prod-web-alb-sg inbound tcp \
  --port-min 80 --port-max 80 --name alb-http-in --vpc vpct-prod
ibmcloud is security-group-rule-add vpct-prod-web-alb-sg outbound tcp --port-min 80 --port-max 80 \
  --remote vpct-prod-web-sg --name alb-http-out --vpc vpct-prod
ibmcloud is load-balancer-create vpct-prod-web-alb public \
  --subnet vpct-prod-web-z1 --subnet vpct-prod-web-z2 --subnet vpct-prod-web-z3 --vpc vpct-prod \
  --family application --sg vpct-prod-web-alb-sg --resource-group-name vpct-lab
ibmcloud is load-balancer-pool-create vpct-prod-web-pool vpct-prod-web-alb round_robin http 5 2 2 http \
  --members "$M" --health-monitor-url / --health-monitor-port 80 --vpc vpct-prod
ibmcloud is load-balancer-listener-create vpct-prod-web-alb --protocol http --port 80 \
  --default-pool $POOL --vpc vpct-prod

Step 3 · Design it

Which kind of load balancer?

This is IBM's comparison. Northgate has two tiers to cover.

Northgate's web tier takes HTTPS from the internet, and the load balancer must end TLS. Which one?

Show the answer

Only the application load balancer ends TLS. The lab adds an HTTPS listener with a certificate from Secrets Manager, and the pool stays plain HTTP.

The app tier listens on TCP port 8080. Only the web servers call it, and it needs low latency. Which one, and public or private?

Show the answer

IBM says network load balancers suit workloads that need low latency and high data throughput. The lab puts a private one in front of the app tier. The web servers call its one address on port 8080.

The app tier must stay reachable if a whole zone fails. A network load balancer sits in one zone. What does IBM say to do?

Show the answer

IBM advises: use Cloud Internet Services Global Load Balancer or Private DNS with several zonal network load balancers for multi-zone availability. Its members can be in all three zones; the load balancer itself is in one.

A floating IP on each server gives no spreading and no health check.

Step 4 · Spot the fault

The pool member that will not go

Northgate has attached an instance group to the web pool, so the group fills it. An admin tries to remove one member by hand.

$ ibmcloud is load-balancer-pool-member-delete vpct-prod-web-alb vpct-prod-web-pool <member-id> --vpc vpct-prod -f
Deleting member r014-f6b0…b4f1 from pool vpct-prod-web-pool
FAILED
Failed to delete member r014-f6b0…b4f1.

FAILED
Error code: member_managed_pool_create_conflict
Error message: Member can not be created. Pool is managed by instance group 'r014-65d0…d2ab'.

Why did the delete fail?

Show the answer

IBM says that with a group attached, members are added to and removed from the pool by the group, based on health checks and its policies. To replace one server, delete its membership. The membership deletes its server, and the group builds a replacement.

The admin deletes a membership. A moment later the pool lists the old server's address as faulted. Do you delete that pool member?

Show the answer

For a short time the pool lists the replaced server's address as faulted. The replacement comes back with generated names for the server, its boot volume, its interface and its membership, so rename them afterwards.

A new pool shows every member faulted, and requests get a 503. The listener and pool settings look right. What do you check first?

Show the answer

A new security group allows nothing outbound, and the load balancer sends its health checks and requests from its own group. The lab adds an outbound rule on port 80 to the load balancer's group, with the web servers' group as the remote.

Step 5 · Check yourself

Four questions

Review question from Unit 3.4. An instance group has four servers at 80%, 70%, 65% and 85% CPU. The policy target is 70%. What does the group do?

Show the answer

Each window the manager adds up the servers' CPU and divides the sum by the target. 300% divided by 70% is 4.29, which rounds up to 5, so the group adds one server.

Where do you send traffic for a public application load balancer?

Show the answer

IBM says the addresses can change with maintenance and scaling. The host name always maps to the current ones.

The load balancer has an HTTPS listener with a certificate, and the pool is HTTP. What is this called?

Show the answer

The load balancer ends TLS and talks plain HTTP to the servers. A redirect listener is the separate setting that sends port 80 clients to the HTTPS listener.

A pool uses round-robin. You set one member's weight to 0. What happens?

Show the answer

Weights apply only to weighted round-robin. Switch the pool's method first, as in step 2. Under that method a weight of 0 sends no new connections and lets existing ones finish.
