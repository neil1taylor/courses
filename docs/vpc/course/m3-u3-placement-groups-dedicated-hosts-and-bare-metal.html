Placement groups, dedicated hosts and bare metal

By the end you can choose between a placement group, a dedicated host and a bare metal server, and say what each one cannot do.

About 10 minutesNo account needed5 steps

Northgate Freight is moving off vSphere. The company is made up; the commands and output are real, recorded in tutorial chapters 33 to 35. Two of its app servers must not fail together, and one workload must not share a host with anyone. Each need has a different answer.

Every command and line of output in this unit comes from real runs in a test account, recorded in tutorial chapters 33 and 34. Bare metal comes from IBM's own pages, cited in chapter 35.

Step 1 · Explore the parts

One dedicated host, one server

A dedicated host is a whole physical node that only your account's servers use. Select a part to see what it does, or click a line.

↑ tap any box

Family and class

A dedicated host belongs to a group. The group, the host and every server on it share one family (balanced) and one class (bx2). A dedicated host is a physical compute node reserved for your account, and only your account's servers run on it.

Watch for this. The supported profile list holds only bx2 profiles. A memory profile will not be accepted. You will see the error in step 3.

Placement switch

When Instance Placement Enabled is off, no new server can be created on the host.

Watch for this. The host cannot be deleted until placement is turned off. You will see that error too.

Capacity

The host has 152 vCPUs and 608 GiB. After one bx2-2x8 server, it shows 150 vCPUs and 600 available. The four NUMA nodes had 38 each; the one holding the server shows 36.

Watch for this. IBM bills the host by the hour. It does not bill the vCPU and memory of the servers on it.

Servers on the host

The host lists the servers placed on it. The server's own record names the host in its dedicated_host field.

Before you run the next command: both servers are running in the group. Can you delete the group?

Show the answer

IBM says a group with servers cannot be deleted, and a server cannot be moved out of a group. To remove a server from a group, delete the server.

ibmcloud is placement-group-delete vpct-prod-app-pg -f
Deleting placement group vpct-prod-app-pg under account <redacted> as user <redacted>...
FAILED
Failed to delete placement group vpct-prod-app-pg.

FAILED
Error code: placement_group_in_use
Error message: placement group is referenced by one or more instances

Delete the servers first, then wait until they are gone, then delete the group.

Step 3 · Spot the fault

Two real errors

Both errors are copied from the chapter's run on a dedicated host.

$ ibmcloud is instance-create vpct-prod-app-z1-bad ... mx2-2x16 ... --dedicated-host vpct-dh-z1-01
FAILED
Error code: bad_field_instance_profile
Error message: instance profile not found in host's supported instance profile list

$ ibmcloud is dedicated-host-delete vpct-dh-z1-01 -f      # with a server already deleted
FAILED
Error code: conflict_field
Error message: Instance placement must be disabled before deleting a dedicated host

The host is a bx2 balanced host and the server asked for mx2-2x16. Why did the create fail?

Show the answerFamily and class must match.

The host's supported instance profile list is bx2-2x8 up to bx2-128x512. The family and class of the group, the host and every server on it must be the same.

The host delete failed. What do you run before you try again?

Show the answerSwitch it off first.

Delete the server, then turn placement off, then delete the host, then the group. In the recorded run, the delete worked once Instance Placement Enabled showed false.

Step 4 · Design it

Pick the right placement

Design it. Two Northgate app servers must not share a host. Other servers may share with other accounts. What do you use?

Show the answer

Host spread puts each server of the group on a separate compute host, up to 12 servers. Power spread is the other strategy: separate power and network supplies, up to four servers.

Design it. One workload must not share a host with other accounts' servers. What do you use?

Show the answer

A dedicated host is for a server that must not share a host with other accounts. Without a group, IBM spreads servers on a best-effort basis, with no guarantee. A server in a placement group does not work with a dedicated host.

Design it. A team wants to install a hypervisor of its own on IBM Cloud. What do you use?

Show the answer

IBM says to pick a bare metal server to install a hypervisor, or for real-time workloads that use physical cores, full memory bandwidth or local storage.

On bare metal in a VMware environment, a PCI interface is an uplink on a vSwitch and a VLAN interface is a virtual network adapter.

Step 5 · Check yourself

Three questions

Review from unit 3.2. A server was created with user data whose runcmd starts a web server. The server is rebooted. Is the web server running?

Show the answer

In the recorded run, the page came back after the first boot. After a reboot, the request failed with Failed to connect.

A bare metal server is powered off for a month. What happens to its billing?

Show the answer

From IBM's pages: a bare metal server powered off keeps its data and keeps billing. A virtual server's billing is suspended when stopped, except for servers on dedicated hosts, and its storage keeps billing.

A server is in a placement group. Can it also run on a dedicated host?

Show the answer

IBM's page on placement groups says placement groups and dedicated hosts do not mix.
