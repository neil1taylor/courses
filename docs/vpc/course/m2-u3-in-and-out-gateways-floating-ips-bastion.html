Unit 3 of Module 2

In and out: public gateways, floating IPs and a bastion

By the end of this unit you’ll be able to choose a way for servers to reach the internet, or to be reached from it, and you’ll know what each choice costs.

About 10 minutesNo account needed5 steps

Northgate Freight is a made-up haulier that is moving off vSphere. The output in this unit is real. Northgate’s network admin has servers that need updates, some that need to take visitors, and admins who need a way in.

Every statement and output in this unit comes from real runs in a lab account, apart from the review question. The NAT comparison is only a rough mapping. We left out some columns and blank lines from the output and shortened the IDs.

Step 1 · Explore the parts

Four ways in and out

Select a part of the drawing to see what it does and which lines of real output show it. You can also click a line of output.

↑ tap any box

Public gateway

You have one per zone. Every server in a subnet attached to it can start connections to the internet, but the gateway accepts none that start on the internet. All its traffic leaves from one public address, a floating IP that the gateway holds.

From vSphere: NAT maps to a public gateway or a floating IP. Source NAT here means that many servers share one address.

Watch for this. A public gateway incurs a monthly charge. The subnet’s ACL and the server’s security group still apply.

Floating IP

A public address that maps to one server’s interface, for traffic in both directions. It works as a one-to-one destination NAT.

Watch for this. It stays in the account after its server is deleted, and it is billed until you release it. If a server has both a floating IP and a public gateway, the floating IP takes precedence. If you remove the floating IP, the server uses the gateway again.

Bastion host

A bastion is a server with a public address that accepts SSH, and it’s the only way in to servers that have none. Here it sits in the management subnet and accepts SSH from your address only. It sends SSH only to servers in a maintenance security group, so it can’t download packages.

Watch for this. A bastion is one more server to patch and watch. A server joins the maintenance group only while someone administers it.

Public address range or firewall

A public address range is a block of public addresses for a zone. You use it only as the destination of a route, with a next hop such as a firewall, so you don’t need a floating IP for each server. The tutorials build the firewall in series 8.

Step 2 · Predict

Pick an answer, then see what IBM and the lab say

A public gateway serves the app subnet. Can a host on the internet start a connection to a server in that subnet?

Show the answer

No. A public gateway lets servers start connections to the internet, but it accepts no connections that start on the internet. A floating IP carries both directions.

A server’s subnet has a public gateway. The server then gets a floating IP. Which does its internet traffic use?

Show the answerThe server uses only one of them at a time.

The floating IP takes precedence. If you remove it, the server uses the gateway again. Associating a floating IP removes the server from the gateway’s many-to-one NAT.

A server with a floating IP is deleted. What happens to the floating IP?

Show the answer

It stays in the account and is billed until you release it. A floating IP is bound to one interface or one public gateway at a time, not to the server’s life.

Step 4 · Design it

Pick a way for each need

Choose an answer for each need, then open the worked answer.

Need A. Northgate’s many app servers need package updates, and none may be reached from the internet. What would you use?

Show the worked answer

A public gateway. One gateway serves a zone, and its servers can start connections but can’t be reached. The cost: a monthly charge for the gateway.

Need B. One short-lived test server must be reachable by a browser from the internet. What would you use?

Show the worked answer

A floating IP carries both directions to one server. The cost: it exposes the server to the internet, so the security group has to limit who can connect. It uses one address per server and is billed until you release it.

Need C. Northgate’s admins must reach several private servers by SSH, through one path that can be audited. What would you use?

Show the worked answer

A bastion suits a few servers and one admin path. The cost: one more server to patch and watch. A floating IP on each server would expose every one of them to the internet.

Need D. All incoming internet traffic must pass a central firewall, and Northgate doesn’t want a floating IP for each server. What would you use?

Show the worked answer

A public address range with a firewall. A public gateway carries outbound traffic only, so it can’t bring internet traffic to a firewall. A public address range is the destination of a route in an ingress route table, with the firewall as next hop. The tutorials build this in series 8.

Step 5 · Check yourself

Three questions

Review question from Unit 2.2. A web request reaches a server. The reply must leave the subnet. Which layer needs its own rule for the reply?

Show the answer

The network ACL. It is stateless, so it checks the reply on its own. The security group is stateful, so a rule that allows traffic one way also allows the replies.

ssh root@<bastion> fails with Permission denied (publickey). The key is right. What is the problem?

Show the answer

The login user. IBM’s bastion tutorial connects as root, but IBM’s Linux connection page gives ubuntu as the default user for Ubuntu images. In the lab, ssh root@ failed with Permission denied (publickey), so the second page is right.

Can one floating IP be bound to two server interfaces at once?

Show the answer

No. A floating IP is bound to one interface or one public gateway at a time.
