Profiles and images

By the end you can read a profile name, say what it gives a server, and check which image and profile go together.

About 10 minutesNo account needed5 steps

Northgate Freight is moving off vSphere. The company is made up; the commands and output are real, recorded in tutorial chapters 30 and 32. In IBM Cloud VPC a server is made from a profile, which sets its size, and an image, which holds its operating system.

Every command and line of output in this unit comes from real runs in a test account, recorded in tutorial chapter 30.

Step 1 · Explore the parts

Read one profile

A profile is the size and capabilities of a server. Select a part of the drawing to see what it means and which lines show it. You can also click a line.

↑ tap any box

Family and architecture

The name bx2-2x8 is a code. IBM's rules: b is the family (balanced), x is the CPU architecture (x86-64) and 2 is the generation. A d as the fourth character would mean a defined amount of instance storage comes with the server.

From vSphere: a vSphere VM maps roughly to a server, which is made from an image and a profile.

Watch for this. There are ten families. The first letter tells you which: b balanced, c compute, m memory.

Size

After the dash, vCPUs come first, then memory in GiB. 2x8 is 2 vCPUs and 8 GiB.

Watch for this. A third generation profile can be resized to a second generation profile, and the reverse.

Speed

The profile caps total bandwidth at 4000 Mbps. IBM splits that between storage and network: for bx2-2x8, 1 Gbps for storage and 3 Gbps for the network. Both parts must be at least 500 MBps.

Watch for this. The Volume bandwidth line shows - here. The server's own output shows the split: volume 1000, network 3000.

Interfaces

The NIC and NAC lines both show one to five for this profile.

Watch for this. The limit grows with size. In the listing, bx2-128x512 allows one to fifteen.

Zones and status

The profile is offered in all three zones of us-east. Its status is current.

Watch for this. IBM's tables show fourth generation profiles (bx4) in the Dallas region. us-east lists none of them.

Step 3 · Predict

Pick an answer, then see what the chapter says

Northgate sees the profile name bx2d-4x16. What does the name say?

Show the answerRead it left to right.

IBM's rules for this example: b balanced, x x86-64, 2 second generation, d a defined amount of instance storage, then 4 vCPUs and 16 GiB after the dash. The vCPUs always come first.

The list holds ibm-ubuntu-22-04-5-minimal-amd64-20 and ibm-ubuntu-24-04-5-minimal-amd64-2. A script picks the first because its build number, 20, is larger. Is that the newer image?

Show the answerDifferent versions.

For two images with the same family, version and type, the larger build number is newer. These two have different versions. IBM also says the naming convention can change and names are not meant to be parsed in scripts: for scripts, use ibmcloud is images --output json.

Step 4 · Design it

Match the tier to the family

Design it. Northgate's customer-facing web servers take moderate to high web traffic. Which family does IBM say suits that?

Show the answer

IBM says Compute suits moderate to high web traffic, production batch processing and front-end web servers. Fewer GiB of memory per vCPU than Balanced.

Design it. Northgate's order system is an in-memory cache. Which family?

Show the answer

IBM says Memory suits memory caching, intensive database applications and in-memory analytics. More GiB of memory per vCPU than Balanced.

Design it. A midsize database with moderate traffic, and the team does not yet know the load. Which family?

Show the answer

IBM says Balanced suits midsize databases and common cloud applications with moderate traffic. The tutorial series keeps bx2-2x8 for its web and app servers: that is a choice for the lab, not IBM's advice.

A d in the name means instance storage: temporary disks on the host that can be lost. Use it for scratch space, not for data you keep.

Step 5 · Check yourself

Three questions

Review from unit 2.1. IBM reserves five addresses in every subnet: the first four and the last. How many addresses does a /24 subnet leave for resources?

Show the answer

A /24 has 256 addresses. IBM reserves five, so 251 are left for resources.

Which part of the profile name cx2d-8x16 tells you it comes with instance storage?

Show the answer

The fourth character d means a defined amount of instance storage comes with the server. Instance storage is temporary.

A custom image is shown as obsolete. What can you do with it?

Show the answer

An image can be available, deprecated or obsolete. A deprecated or obsolete image is still billed until it is deleted, and you cannot create a server from an obsolete image.
