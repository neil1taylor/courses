vSphere words, VPC words

By the end you can name the VPC word closest to each vSphere and NSX word you use, and say where the closest word misleads.

About 10 minutesNo account needed5 steps

Northgate Freight is moving its vSphere estate to IBM Cloud VPC. The company is made up; the output in this unit is real. Its admins have a list of vSphere words and want the VPC word for each.

Step 1 · Explore the map

Five groups of words

Each line pairs a vSphere or NSX word with the closest VPC word. The pairs are rough, for orientation. Select a group in the drawing to see where its words differ. You can also click a line.

↑ tap any box

Place

A VPC spans the zones of one region. Zones are separate data centres.

From vSphere: roughly, a region is a separate site with its own vCenter, and a zone is a separate cluster with its own power and network.

Network and security

A subnet lives in one zone. The VPC and its subnets take the place of the distributed switch and its segments. The route table and the Transit Gateway take the place of the NSX routers.

Watch for this. The NSX distributed firewall becomes a security group, which is applied to a network interface. The NSX gateway firewall becomes a network ACL, which is applied to a whole subnet and has no state. They are not one firewall.

Servers

A VM becomes a virtual server instance, called a server here. IBM makes it from an image, which is the operating system of its boot volume, and a profile, which is its size. An instance group repairs and scales servers.

Watch for this. The closest word to vMotion is live migration, which IBM does for its own host maintenance. Step 3 shows what it records.

Storage

A datastore becomes a block storage volume or a file share. A VMDK becomes a boot or data volume. A VPC snapshot is a point-in-time copy of one volume.

Watch for this. A snapshot is kept in a regional storage repository. A copy in another region is a separate step.

People and tools

vCenter tags become tags and access tags, which do different jobs. vCenter roles and permissions become IAM access groups and policies. vRealize and Aria Automation become Terraform and Schematics.

Unit 1.3 covers access groups. Unit 1.4 covers Terraform and Schematics.

Step 3 · Predict

Pick an answer, then see what the lab recorded

Northgate's VMs have fixed addresses. By default, where does a new server's primary address come from?

Show the answerReserve first to keep it.

By default IBM picks the address and names the reserved IP. The reserved IP is created for the server and deleted with it. If the address must be known before the server exists, or must outlive it, you reserve an address first and set auto-delete to false.

IBM updates the host under a running server. In the usual live-migration case, what does the server's owner see?

Show the answerNot a move you ask for.

IBM's maintenance page says a nondisruptive live migration pauses the server for about 10 seconds, sometimes up to 30, with no restart and no notice in advance. A disruptive migration restarts the server, with notice. Servers with a GPU profile are not live-migrated: they restart, with notice.

Step 4 · Design it

One rule for the whole subnet

Northgate's web subnet holds several servers. An address on the internet is sending bad traffic, and Northgate wants one rule that covers every server in the subnet.

Which VPC object gives you one place to write that rule?

Show the worked answer

A network ACL applies to whole subnets, not to individual servers. Its rules are stateless, so each direction needs its own rule. A security group is attached to a network interface, so it works server by server, and its rules are stateful.

The NSX word for the ACL is the gateway firewall. The word for the security group is the distributed firewall. Do not treat them as one.

Step 5 · Check yourself

Three questions

Review question from Unit 1.1. A server in zone 1 must reach a server in zone 2 of the same VPC. What routing do you add?

Show the answer

Every subnet in a VPC reaches every other subnet through the implicit router, across zones, with no routes to add.

Northgate used vRealize Automation to build estates from blueprints. Which VPC words does the map pair with it?

Show the answer

The map pairs vRealize and Aria Automation with Terraform and Schematics. Unit 1.4 shows both. The tags and the groups are other rows of the map.

Which VPC idea is closest to a vSphere port group, and what is different?

Show the answer

The map pairs a port group or VLAN with a subnet, and an NSX segment with a subnet placed in one zone. A subnet cannot span zones.
