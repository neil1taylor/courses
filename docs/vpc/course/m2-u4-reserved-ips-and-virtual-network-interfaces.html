Reserved IPs and virtual network interfaces

By the end you can read a server’s network interface and its addresses, say which addresses IBM owns, and say what the IP spoofing check drops.

Step 1 · Explore the parts

One interface, its addresses and its settings

Select a part of the drawing to see what it does and which lines of real output show it. You can also click a line.

↑ tap any box

Virtual network interface

A network interface that is its own resource. A server joins it through a network attachment, here nic0. It holds a primary address, security groups and an optional floating IP, and it can outlive the server.

Watch for this. Each interface of a server is on a different subnet in the same zone. IBM says new features are added only to virtual network interfaces, and a server cannot mix them with the older instance network interfaces.

Reserved IP

A private address in a subnet that is a resource of its own, with a name. The server’s primary address, 10.20.0.4, is one: vpct-prod-web-z1-01-ip0. IBM picked it when the server was created, and the line shows true for auto delete.

From vSphere: the closest term misleads. A server’s primary address is a reserved IP, and you can fix it.

Two settings

The IP spoofing check drops an outbound packet whose source address is not the interface’s own. The output reads Allow source IP spoofing false, so the check is on. Enable Infrastructure NAT true means the VPC does the NAT for the interface’s floating IP.

Watch for this. To attach a virtual network interface to a virtual server, infrastructure NAT must be on.

IBM’s five addresses

The first four addresses and the last belong to IBM: the network address .0, the default gateway .1, the DNS address .2, a reserved address .3 and the broadcast address .255. Their owner is provider and they have no target. That is why a /24 leaves 251.

Step 2 · Predict

Pick an answer, then see what the chapters say

IBM picked the server’s address when the server was created, and the reserved IP shows Auto delete true. The server is deleted. What happens to that reserved IP?

Show the answer

When IBM picks the address, the reserved IP is created for the server and deleted with it.

Northgate needs a server address that is known before the server exists, and kept after the server is gone. What do you do?

Show the answer

You reserve an address first when it must be known before the server exists, or must outlive it. Set auto-delete to false to keep it.

An older script uses an instance network interface. Can the same server also take a virtual network interface?

Show the answer

The style is fixed when the server is created, and an older instance network interface cannot be changed into a virtual network interface.

Inside the server, will the secondary address 10.20.0.50 show on one of the interfaces?

Show the answer

Reserving an address and binding it to the interface does not configure it in the guest. The next command shows it.

# inside the server, after ssh -i ~/.ssh/id_ed25519 ubuntu@$FIP
ip -br addr

ens3             UP             10.20.0.4/24 fe80::1ff:fef5:521b/64 
ens9             UP             10.20.1.4/24 metric 1024 fe80::1ff:fef5:521c/64

Named ens3 and ens9, not eth0 and eth1.

10.20.0.50 is on no interface. The second interface came up with its address by itself on this Ubuntu image.

The second interface, ens9, is up. Why can traffic that leaves by it fail?

Show the answer

The next command shows one default route, on ens3. Traffic that leaves by ens9 can fail until you add a static route or a separate routing table.

ip route

10.20.0.0/24 dev ens3 proto kernel scope link src 10.20.0.4 
10.20.0.1 dev ens3 proto dhcp scope link src 10.20.0.4 metric 100

Step 4 · Design it

Pick a setting for each need

Choose one, then open the worked answer. The answers come from chapters 26 and 28.

Need A. A server will forward traffic for other addresses, as a firewall does when it is a route’s next hop. What must change?

Show the worked answer

The check drops outbound packets whose source address is not the interface’s own, so a forwarding server needs it turned on. The cost: only a user with the IAM role IP Spoofing Operator can change it, and the role is off for all users by default.

Need B. One virtual server’s interface must hold two floating IPs.

Show the worked answer

To attach an interface to a virtual server, infrastructure NAT must be on. With it on, an interface can have one floating IP. Several floating IPs need infrastructure NAT off and IP spoofing on, and such an interface can be used only by a bare metal server.

Need C. A server address must be fixed before the server exists, and must survive the server.

Show the worked answer

An address IBM picks is created for the server and deleted with it. Reserve it yourself when it must be known first or must outlive the server.

Step 5 · Check yourself

Three questions

Review question from Unit 2.3. Which one carries traffic both ways between a server and the internet: a public gateway or a floating IP?

Show the answer

A floating IP gives both directions. A public gateway gives outbound connectivity only.

Who can change the IP spoofing setting on an interface?

Show the answer

The role is off for all users by default. MAC address spoofing is different: it is always dropped, and that check cannot be turned off.

In the subnet 10.20.0.0/24, whose address is 10.20.0.1?

Show the answer

It is ibm-default-gateway, owned by the provider. The DNS address is 10.20.0.2, and the server’s own address starts at 10.20.0.4.
