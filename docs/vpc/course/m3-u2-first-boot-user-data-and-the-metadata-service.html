Unit 2 of Module 3

First boot: user data and the metadata service

By the end you can read a cloud-init user data file, say what runs and when, and say what must never go in it.

About 10 minutesNo account needed5 steps

Northgate Freight is moving off vSphere. The company is made up; the commands and output are real. A new web server sets itself up from a text file, with no one logged in.

Every command and line of output in this unit comes from a real run in a test account.

Step 1 · Explore the parts

Read the user data

User data is text you give to a server when you create it. Cloud-init reads it. The limit is 64 KB. Select a part to see what it does, or click a line.

↑ tap any box

First line

#cloud-config marks the file as cloud-config, a YAML format that cloud-init reads. The other option is a shell script, which must start with #!/bin/bash.

Watch for this. Stock images are cloud-init enabled. Fedora CoreOS takes Ignition instead, and Windows servers use Cloudbase-init.

write_files

Writes a file to the server's disk. Here it writes one line of text to /srv/web/index.html.

runcmd

Runs a command at first boot. This one starts Python's built-in web server on port 80. It needs no internet, because the web subnet has no public gateway.

Watch for this. Cloud-init runs this once. A rebooted server does not start the web server again. You will see that in step 2.

#cloud-config
write_files:
  - path: /srv/web/index.html
    content: |
      configured by cloud-init on vpct-prod-web-z1-02
runcmd:
  - [ sh, -c, "cd /srv/web && nohup python3 -m http.server 80 >/var/log/web.log 2>&1 &" ]

Before you run the next command: the server is rebooted, then you ask for the same page. What comes back?

Show the answer

Cloud-init runs this user data once, on the first boot. A rebooted server does not start the web server again.

# after a reboot

curl -m 5 http://$FIP/
curl: (7) Failed to connect to 169.63.96.23 port 80 after 99 ms: Could not connect to server

First boot only. To start a service on every boot, the user data would have to do more than this.

Status is done. The warning is about the default user's password, which this user data does not set.

Step 3 · Predict

Pick an answer, then see what really happened

Northgate creates a server and does not pass --metadata-service true. Can a process on the server read its metadata?

Show the answerOff unless you turn it on.

IBM says access to the metadata service is off by default. The servers created without the option show Metadata service Enabled false.

On the server, the token request worked while the service was on. After --metadata-service false, the same request is made. What does curl do?

Show the answerNo answer at all.

The recorded run: with the service on, the request returned a token 1836 characters long. With it off, the request got no answer and curl gave up (rc=28).

The token lives 5 minutes unless you ask for longer. The recorded run asked for 3600 seconds.

A teammate wants to put the database password in user data, because only the server can read it. What does this output tell you?

Show the answerRead it back, plain.

IBM says metadata is not encrypted and any process on the server can read it. Do not store passwords or customer encryption keys in user data.

cloud-init status said extended_status: degraded done, with a warning. Did the user data run?

Show the answer

The status was done and the page text came back from the web server the user data started. The warning says lock_passwd is set for ubuntu with no password given. Cloud-init ran; the user data does not set that password.

Step 5 · Check yourself

Three questions

Review from unit 3.1. In the profile name bx2-2x8, what does 2x8 mean?

Show the answer

After the dash, vCPUs come first, then memory in GiB: 2 vCPUs and 8 GiB.

Design it. Northgate needs the same set-up on many servers, built once. A different team only needs to change a few small things on a stock image. Which option fits each?

Show the answer

A custom image suits the same set-up on many servers, built once. Cloud-init user data on a stock image suits small changes, with no image to maintain.

Where should a database password for a new server go?

Show the answer

IBM says metadata is not encrypted and any process on the server can read it. The 64 KB limit is about size, not safety.
