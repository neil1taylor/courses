Unit 1 of Module 1

How a client-to-site VPN reaches a VPC

By the end of this unit you'll be able to say what a VPN server, a client IP pool and a VPN route each do, pick the right way for administrators to reach private servers, and find why a connected client reaches nothing.

About 10 minutesNo account needed5 steps

Northgate Freight is a made-up haulier moving its vSphere estate to IBM Cloud VPC. Its administrators work from laptops, and they need a way into the production VPC without opening every server to the internet.

Every command and line of output in this unit comes from a real run, and the limits come from IBM's pages.

Step 1 · Explore the parts

A server, a pool and a route

A client-to-site VPN server accepts OpenVPN connections from individual clients. Select a part of the drawing to see what it does and what limits IBM sets on it.

↑ tap any box

VPN server

A VPC service that accepts OpenVPN connections. IBM says it authenticates by certificate, by user ID and passcode, or both, and that its default port is 443 and its default protocol UDP. It can use up to two subnets, in different zones, for high availability.

Watch for this. A server created in the lab sat in the subnet vpct-prod-vpn-z1 and was stable and healthy about 100 seconds after the create.

Client IP pool

The range the server hands out to connected clients. This one is 172.16.0.0/22.

Watch for this. IBM says the pool must not overlap any address prefix of the VPC, 127.0.0.0/8, 161.26.0.0/16, 166.8.0.0/14, 169.254.0.0/16 or 224.0.0.0/4, and its prefix length is between /9 and /22.

Security group

The VPN server's group allows UDP 443 in, and everything out. A new group allows nothing out, so the outbound rule is added too.

Watch for this. The inbound rule is open to the internet on UDP 443.

VPN route

A rule on the server that says where traffic for a destination goes. The action deliver sends it into the VPC and keeps the client's address. The action translate changes its source address to the VPN server's private address, which hides the client address. The action drop blocks the traffic.

Watch for this. IBM says traffic that matches no route is dropped. With one route, to 10.20.0.0/16, only that range is reachable.

Split tunnel

A client setting that sends only the VPC's traffic through the VPN. It is off by default.

Watch for this. Without it, the client's default route goes into the tunnel, and an SSH session to the client itself is lost.

ibmcloud is security-group-create vpct-prod-vpnserver-sg vpct-prod --resource-group-name vpct-lab
ibmcloud is security-group-rule-add vpct-prod-vpnserver-sg inbound udp --port-min 443 --port-max 443 --remote 0.0.0.0/0 --name vpnserver-udp443-in --vpc vpct-prod
ibmcloud is security-group-rule-add vpct-prod-vpnserver-sg outbound all --remote 0.0.0.0/0 --name vpnserver-all-out --vpc vpct-prod
ibmcloud is vpn-server-create --name vpct-prod-vpnserver --vpc vpct-prod --subnet vpct-prod-vpn-z1 \
  --client-ip-pool 172.16.0.0/22 --cert <server-secret-crn> --client-auth-methods certificate \
  --client-ca <client-ca-secret-crn> --sg vpct-prod-vpnserver-sg --resource-group-name vpct-lab
ibmcloud is vpn-server-update vpct-prod-vpnserver --vpc vpct-prod --enable-split-tunnel true
ibmcloud is vpn-server-route-create vpct-prod-vpnserver --vpc vpct-prod --destination 10.20.0.0/16 --action deliver --name vpct-prod-vpnserver-to-prod
Step 2 · Choose it

Pick a way in for each need

A client-to-site VPN is one of three ways to reach private servers. Pick one for each need, then read the worked answer.

Many administrators need to reach a whole VPC range, each from their own laptop. What should Northgate use?

Show the worked answer

A client-to-site VPN. It suits many administrators and access to a whole VPC range, and it needs certificates and a client program on each laptop.

Only a few servers need to be reached, and one SSH hop is enough. What should Northgate use?

Show the worked answer

A bastion host. It reaches a few servers with one SSH hop.

A whole site, not a person, must reach the VPC. What should Northgate use?

Show the worked answer

A site-to-site VPN. It joins a site to the VPC and is built in a later chapter of the tutorials.

The downloaded file does not end with a newline. Add one before the client certificate, or OpenVPN stops with Cannot parse argument '0<cert>' as non-negative integer.

The profile now holds the client's certificate and key. What does OpenVPN print when the tunnel is up?

Show the answer

Initialization Sequence Completed. That line in the log means the connection succeeded.

sudo openvpn --config client.ovpn --daemon --log ovpn.log; ip -4 addr show tun0; ip route | grep tun0
3: tun0    inet 172.16.0.130/25 brd 172.16.0.255 scope global tun0
10.20.0.0/16 via 172.16.0.129 dev tun0 metric 200
172.16.0.0/22 via 172.16.0.129 dev tun0 metric 200
172.16.0.128/25 dev tun0 proto kernel scope link src 172.16.0.130

The client got 172.16.0.130 from the pool, and the server pushed the route to 10.20.0.0/16.

Step 4 · Predict and spot the fault

What the server sees, and what to check

The route's action is deliver. From a private server, which source address does a connection from the connected laptop show?

Show the answer

The pool address, 172.16.0.130. The action deliver does not change it. With translate a server sees an address of the VPN server's VPC instead, and security groups must allow that address.

The tunnel is up and the log ends with Initialization Sequence Completed, but SSH to a private server times out. Where do you look first?

Show the answer

At the route, the route table, and the target's security group and ACL. The route may be missing, the route table may not accept the pool's routes, or a security group or network ACL may deny the pool. A network ACL needs a rule for each direction. The certificate and the UDP 443 rule worked, or the tunnel would not be up.

Step 5 · Check yourself

Three questions

Which range must the client IP pool not overlap?

Show the answer

Any address prefix of the VPC. IBM also lists 127.0.0.0/8, 161.26.0.0/16, 166.8.0.0/14, 169.254.0.0/16 and 224.0.0.0/4, and the pool's prefix length is between /9 and /22.

A private server shows the VPN server's VPC address instead of the pool address. Which route action is set?

Show the answer

translate changes the source address. deliver leaves the pool address in place, and drop blocks the traffic.

A client has the split tunnel off. What does it send into the tunnel?

Show the answer

Its default route goes into the tunnel, so an SSH session to the client itself is lost. A split tunnel sends only the VPC's traffic through the VPN.

Remember

The server hands each client an address from its pool, and a route says where that traffic goes. Traffic that matches no route is dropped. With deliver a private server sees the pool address. A connected client that reaches nothing is a route, route table, security group or ACL problem.
