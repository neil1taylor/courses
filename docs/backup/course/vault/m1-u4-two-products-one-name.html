Unit 4 of Module 1

The vault and the Deployable Architecture are different products

By the end of this unit you'll be able to name both products, say which one this course teaches, and use the right name in a paper for Northgate's directors.

About 10 minutesNo account needed4 steps

Northgate Freight is a made-up haulier. A colleague sends Northgate's backup admin a link that says "cyber vault". Before using anything on it, the admin needs to work out which of two IBM products the link is about.

Everything this unit says about the Deployable Architecture comes from reading IBM's catalog code and docs. We never deployed it in our lab, so none of it is tested. Everything we tested in this course is IBM Cloud Cyber Vault.

Terms used. Terraform: a tool that builds cloud resources from written instructions. HMAC key: a pair of an access key ID and a secret key that object storage accepts for requests.

Step 1 · Explore the parts

Two products side by side

Both products give you a cyber vault for backups, but they're different products and they're built in different ways.

Which product is made by one API call and has two keys, one for writing and one for reading?

Show the answer

IBM Cloud Cyber Vault. IBM's docs describe it as a managed COS feature, where one call creates a hardened bucket with credentials and network rules. The Deployable Architecture is a Terraform architecture in the IBM Cloud catalog. It builds ordinary resources in the customer's account, with one HMAC key.

Which of the two did we deploy and test in our lab?

Show the answer

IBM Cloud Cyber Vault only. We never deployed the Deployable Architecture here. We decided to describe both and test the vault.

Which product builds its resources in the customer's own account, from a Terraform architecture in the IBM Cloud catalog?

Show the answer

The Deployable Architecture. IBM describes it as a Terraform architecture that builds ordinary resources in the customer's account. IBM Cloud Cyber Vault is made by one call to COS, and its vault sits in an account that IBM manages. We read the architecture's code and didn't run it.

Step 3 · Spot the fault

A result that belongs to the other product

A colleague at Northgate writes in a summary: "We tested the cyber vault, so we know the lock default is at least one year." What's wrong with that?

What's wrong with the sentence?

Show the answer

It mixes the two products. In the code we read, the architecture's lock is at least 1 year when the lock is on. Cyber Vault takes 0 to 3,650 days, and our tests used a 3-day maximum.

When Northgate writes about these results, which name should it use?

Show the answer

IBM Cloud Cyber Vault, which is the name in our test records. You'll also see it written "IBM COS Cyber Vault". The backup software on the other side is IBM Storage Defender Data Protect 7.4.1 (Defender 2.2.1).

Watch for this. When a page or a colleague says only "cyber vault", they could mean either product. Ask which one before you reuse any number.
