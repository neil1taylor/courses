The vault and the Deployable Architecture are different products

By the end you can name both products, say which one this course teaches, and write the right name in a board paper.

About 10 minutesNo account needed4 steps

Northgate Freight is a made-up haulier. A colleague sends it a link that says "cyber vault". Northgate must find out which of two IBM products the link is about.

What this unit says about the Deployable Architecture was read from IBM's catalog code and docs on 25 September 2026. It was never deployed in our lab, so none of it is tested. Everything tested in this course is the Beta, in us-south, with no SLA and no support.

Terms used. Terraform: a tool that builds cloud resources from written instructions. HMAC key: a pair of an access key ID and a secret key that object storage accepts for requests.

Step 1 · Explore the parts

Two products side by side

Both are about a cyber vault for backups. They are different products and are made in different ways.

Which product is made by one API call and has two keys, one for writing and one for reading?

Show the answer

The Beta. IBM's docs, dated 27 August 2026, describe a managed COS feature: one call creates a hardened bucket with credentials and network rules. The Deployable Architecture is a Terraform architecture in the IBM Cloud catalog that builds ordinary resources in the customer's account, with one HMAC key.

Which of the two did we deploy and test in our lab?

Show the answer

The Beta only. The Deployable Architecture was never deployed here. Our decision of 25 September 2026 was to document both and test the Beta.

Step 3 · Spot the fault

A result that belongs to the other product

A colleague writes in a summary: "We tested the cyber vault, so we know the lock default is at least one year."

What is wrong with the sentence?

Show the answer

When the lock is on, the architecture's lock is at least 1 year in the code we read. The Beta takes 0 to 3,650 days, and our tests used a 3-day maximum. The sentence mixes the two.

Which name should a statement from this course use?

Show the answer

The Beta, by its recorded name. It is also written "IBM COS Cyber Vault (Beta)". The backup software on the other side is IBM Storage Defender Data Protect 7.4.1 (Defender 2.2.1).

Watch for this. A page or a colleague that says only "cyber vault" may mean either product. Ask which one before you reuse any number.
