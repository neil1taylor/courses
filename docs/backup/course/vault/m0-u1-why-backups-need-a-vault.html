Why backups need a vault

By the end you can say why an attacker goes after the backups, what Defender Data Protect does, what a Cyber Vault adds, and the words the rest of the course uses.

About 10 minutesNo account needed5 steps

Northgate Freight is a made-up haulier. It backs up its servers with Defender Data Protect. Its board asks: if an attacker gets in, will the backups still be there?

No experience of vaults or Data Protect is needed. Results quoted here come from tests in our lab in October and November 2026; later units show each one in detail.

Step 1 · Explore the parts

From server to vault

Data Protect backs up servers and keeps the copies on its own cluster. It can also send a second copy, an archive, somewhere else. A Cyber Vault is a place for that second copy that nobody can delete early. Tap each part.

↑ tap any box

The source

A server, database or VM that you back up. In this course the sources are a Linux server, a Windows server and a SQL Server database.

The Data Protect cluster

IBM Storage Defender Data Protect is backup software: Cohesity DataProtect with an IBM name. The cluster runs it. It copies each source on a schedule and keeps those backups on its own disks. A policy says when to back up, how long to keep each backup, and whether to archive it.

The archive

A second copy of a backup that the cluster sends to an external target: storage outside the cluster. Here the external target is the vault. If the cluster is lost, the archive can still be read.

The bucket

The vault is built on IBM Cloud Object Storage. Object storage keeps data as objects, whole stored items each with a name, inside a container called a bucket. The vault's bucket keeps versions: writing to a name again adds a new version and keeps the old one.

The object lock

Each archived object gets a lock date, set by Data Protect from the policy's archive retention, which is how long a copy is kept. Until that date the object cannot be deleted and its lock cannot be shortened. The lock is in compliance mode, the strict kind.

The write key

A key is a pair of values that a program sends with each request to prove what it may do. The write key goes to the Data Protect cluster, so it can archive into the vault.

The read key

Kept apart from the backup system and used only to recover. A new cluster that has only the read key can find the archives in the vault and restore them.

The allow-list and the write window

The allow-list names the only networks the vault answers. A request from anywhere else is refused, even with a valid key. A write window is an optional daily time slot; outside it the vault refuses requests.

Step 2 · Predict

The attack without a vault

Suppose Northgate keeps its backups only on its Data Protect cluster. An attacker gets the backup admin's login. They delete the backups, then overwrite the data on every server.

What can Northgate restore?

Show the answer

A backup helps only if it outlives the attack. If one login can delete every copy, an attacker with that login can leave nothing to restore.

Step 3 · Predict

What a lock means

Now the attacker has the vault's write key too, and works from a server inside the allowed network. They try to delete a locked archive object before its lock date.

What does the vault do?

Show the answer

In our lab on 5 October 2026 every try was refused with "Access Denied because object protected by object lock". Tries to change the lock date were refused too.

The same attacker tries from a server outside the allow-list. What happens?

Show the answer

In our lab on 6 October 2026 a valid write key used from a network not on the list was refused.

Watch for this. A lock stops deletion, not every change. A holder of the write key could still write a new version on top of a test object; the old version stayed. Unit 1.1 shows it.

Step 4 · Design it

Where each key goes

Northgate makes a vault and gets its two keys. Now the worst case: the attack also destroys the Data Protect cluster.

Where does Northgate keep the read key?

Show the answer

The steps in the IBM Cloud console say to give the write key to the backup cluster and keep the read key apart. An attacker who takes the backup system should not also get the key that recovers it.

The old cluster is gone. What does Northgate need to get its data back?

Show the answer

In our lab on 10 November 2026, after the attack and the loss of the cluster, a new cluster with only the read key brought back all three workloads as they were before the attack. Module 4 walks through it.

The Cyber Vault is a Beta: it runs only in the us-south region (Dallas), and IBM gives no service level agreement (SLA) or support for it. Unit 1.3 covers its terms.
