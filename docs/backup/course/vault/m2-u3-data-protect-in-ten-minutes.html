Unit 3 of Module 2

Defender Data Protect in ten minutes

By the end you can say what a cluster, a source, a policy and a protection group are, and where a one-node cluster runs on IBM Cloud VPC.

About 10 minutesNo account needed5 steps

Northgate Freight is a made-up haulier. It already backs up with Defender Data Protect. Before it adds a vault, its team learns the four words the console uses.

Everything here comes from the Data Protect builds and runs in our lab on 5 October and 10 November 2026. Product: IBM Storage Defender 2.2.1 Data Protect, version 7.4.1.

Terms used. Agent: a small program on a server that lets the cluster back it up. KVM: a Linux feature for running virtual machines. Bare metal server: a physical server that one customer rents whole. Image: a ready-made disk file used to start a machine. Node: one machine in a cluster. OpenShift: Red Hat's platform for running software, and virtual machines, in clusters.

Step 1 · Explore the parts

Four words

The cluster is Data Protect itself, managed from its own console and API. It backs up sources. A policy says when and how long. A protection group joins what you protect to a policy.

Which one says how long a backup is kept and whether it is archived?

Show the answer

The policy is a daily backup, 1 day on the cluster, and every run archived to the vault for 1 day.

You click Run Now. On which of the four do you click it?

Show the answer

In our lab each of three groups was run with Run Now. The dialog carried the policy's archive line, so no archive target had to be chosen. On the Policies page the console counts the groups that use each policy.

In our lab a source was a VPC virtual server with an agent and 19 GiB of test data. The cluster serves its own Linux agent, so no separate download was needed.

Step 2 · Explore the parts

Where the cluster runs on IBM Cloud

IBM ships the cluster as an image for KVM. In our lab it ran as one node, inside a KVM guest, on a VPC bare metal server.

Northgate wants the cluster on IBM Cloud VPC. Where do you put it?

Show the answer

IBM ships no image for VPC virtual servers, OpenShift or OCI, and Cohesity does not support a cluster on VPC virtual servers.

Which software version did the lab install?

Show the answer

Only 7.3.x and 7.4.x are supported. Support for 7.2.x ended on 8 June 2026.

Is a licence needed to run backups?

Show the answer

Defender is licensed in Resource Units. The lab applied no licence on 5 October 2026 and the cluster ran backups and archives. It did not check what the console says about an unlicensed cluster.

Step 4 · Spot the fault

Two traps in the build

Northgate's team follows the October steps on 10 November 2026. Two things have changed.

The first run of the install script stops at once with "Permission denied", exit code 126. Why?

Show the answer

In our lab on 10 November 2026 the download had no execute bit. After chmod +x on the copy it ran.

In October the boot disk was nvme3n1. What do you do on 10 November?

Show the answer

The boot disk changed between builds. On 10 November 2026 the lab checked first, then formatted the other two disks.

Watch for this. Set the cluster's host name when you create it. A cluster built without one cannot back up OpenShift VMs, and the name cannot be changed later.

Step 5 · Check yourself

Three questions

What joins what you protect to a policy?

Show the answer

The group has one policy, and you run the group.

Where does a Data Protect cluster run on IBM Cloud VPC?

Show the answer

Cohesity does not support a cluster on VPC virtual servers.

The boot disk name was different from the last build. What do you do?

Show the answer

It was nvme3n1 on 5 October and nvme0n1 on 10 November 2026.
