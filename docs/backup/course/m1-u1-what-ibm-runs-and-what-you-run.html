Unit 1 of Module 1

What IBM runs and what you run

By the end of this unit you'll know which parts of IBM Cloud Backup and Recovery IBM runs, which parts you deploy and install, and how you buy it and sign in.

About 10 minutesNo account needed4 steps

Northgate Freight is a made-up haulier. It has Linux and Windows servers on IBM Cloud, and its directors want to know who would look after what if it used BRS. In this unit you find out.

Nothing in this unit was run in a lab. Every statement comes from IBM's own documents, and is recorded in the overview and architecture pages of this repository. No real address or name appears.

Step 1 · Explore the parts

Who runs which piece?

BRS has a part that IBM runs and parts that sit on your side. Tap a part of the drawing to see what it is. You can also click a line.

↑ tap any box

The service instance

IBM operates the service instance, which is the control plane: the dashboard and the API. IBM operates it in a region you pick. You create the instance from the IBM Cloud catalog, in a region and a resource group, and each instance has its own dashboard. IBM creates the default policies; you create the ones that fit your needs.

The dashboard is the Cohesity interface under an IBM name.

Backup storage

IBM stores backups in "regionally durable storage" in the same region as the instance. IBM spreads the service across the zones of that region. You never create a bucket.

The connector

A server that links your network to the service. On a VPC it's a server in your own VPC, built from an IBM catalog image, and you deploy it. On VMware it's a VM from an OVA, and on a cluster it runs from a Helm chart.

Watch for this. IBM's shared-responsibility page and its connector page say different things about who upgrades the connector, so this unit doesn't say.

The Connector Agent

A small service on the source host. It replaces the connector server for that host. You install it.

The backup agent

It runs on each protected server or database host. You install it and you upgrade it.

Piece                  Runs where               Who
Service instance       a region you pick        IBM
Backup storage         the same region          IBM
Data Source Connector  a VSI in your VPC        you deploy
Connector Agent        on the source host       you install
Backup agent           each protected server    you install and upgrade
Step 2 · Spot the fault

What the note to the directors gets wrong

Northgate's IT manager has summed up IBM's service for the directors in one sentence. Which part of it is wrong?

The note says: "IBM runs the whole service, so nothing is installed on our servers and nothing is deployed in our VPC." What's wrong with it?

Show the answer

IBM runs the back end, and you deploy the connectors and install the agents. IBM's shared-responsibility page splits it that way: IBM runs and scales the back end across the zones of a region, and you deploy and scale the connectors and agents. The service is agent-based.

A backup agent on one Northgate server is out of date. Whose job is the upgrade?

Show the answer

It's yours. The responsibility table lists "Upgrades backup agents" on the customer side. IBM upgrades the back end.

Watch for this. The same table says you create the policies that fit your needs and manage your own encryption keys. IBM creates tenants, endpoints, networking, storage and the default policies.

Step 3 · Predict

Buying it and signing in

Northgate already has an IBM Cloud account. Before it orders anything, its finance team wants to know how it pays, and its security team wants to know how people sign in.

How does Northgate pay for BRS?

Show the answer

On its IBM Cloud bill. BRS is sold as a normal IBM Cloud service: you create an instance from the catalog, and it's billed on the IBM Cloud bill. Sign-in uses IBM Cloud IAM, not a MyCohesity account.

How does a person at Northgate open the dashboard of an instance?

Show the answer

From the IBM Cloud console. IBM's pages say access is controlled by IBM Cloud IAM, and that users open the dashboard from the IBM Cloud console. IAM roles can cover all instances or one instance. IBM's pages don't describe how single sign-on or multi-factor sign-in works for this service.

Step 4 · Check yourself

Three questions

Who installs the backup agent on a protected server?

Show the answer

You do. You install and upgrade the backup agents, and you also deploy the connectors and install the Connector Agents.

A zone in the region fails. IBM keeps the service running. Whose job is it to restore Northgate's own workloads into another zone?

Show the answer

Yours. IBM keeps the service running if one zone fails, and you restore your own workloads into another zone.

Which name do the IBM Cloud CLI, IAM and the endpoint hostnames use for the service?

Show the answer

backup-recovery. BRS appears in IAM docs and module names. BARS doesn't appear on any public IBM page we found; it's an internal name.
